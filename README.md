
# Simple Calculator Android App

## About
Simple Calculator is an Android application developed using Kotlin and XML in Android Studio. It allows users to perform basic mathematical operations through a simple, user-friendly interface.

## Features
- Addition of two numbers
- Subtraction of two numbers
- Multiplication of two numbers
- Division of two numbers
- Division-by-zero error handling
- Help and instructions dialog
- Separate screens for each operation
- Back buttons to return to the home screen

## Technologies Used
- Kotlin
- XML
- Android Studio
- Android SDK

## Project Structure
The application contains a home screen and four operation screens:
- MainActivity
- AddNumbersActivity
- SubtractNumbersActivity
- DivideNumbersActivity
- MultiplyNumbersActivity

## How to Run
1. Install Android Studio.
2. Clone or download this repository.
3. Open the project in Android Studio.
4. Allow Gradle synchronization to finish.
5. Start an Android emulator or connect an Android device.
6. Click Run to launch the application.
